== ⚇ ddot.it &ndash; Connect anything with everything
ddot.it is a *simple syntax* for mixing documents and knowledge graphs.

.Simple Syntax
* ddot.it uses only double-dot (`..`) and double-comma (`,,`).
* *Ergonomic*: ⌨️ Easy to type, even on mobile keyboards.
* *AI ready*: 🤖Token-efficient and Markdown-compatible.
* ddot.it can be used *wherever you can enter text*.

* Add links, annotations and structured data directly into your existing *decentralized documents*: +
 link:reader/reader-markdown.html[Markdown] files, link:reader/reader-java.html[Java]Doc comments, Google Context notes field, link:reader/reader-powerpoint.html[PowerPoint] slide notes, Confluence pages, Maven pom.link:reader/reader-xml.html[xml] files, Word documents, email text, Docker compose link:reader/reader-yaml.html[yaml] files, link:reader/reader-html.html[web pages], …
* By using the same concepts, a single web of knowledge is formed – *across tool boundaries*.
* You get an enterprise (or personal) *knowledge graph*, giving humans and agents a shared understanding of core concepts.

*How does it work?*

A uniform 'triple' structure for *typed links*, *simple links*, and *properties*.

[.diagram.diagram-sm]
image::triple-structure.svg[]

. Each *ddot reader* knows how to read one kind of source and extracts the triples from the ddot.it text.
. A *ddot collector* uses a number of readers to read all sources, periodically.
** Your sources remain the single source of truth. Triples are just cached.
. All triples are *combined into a single knowledge base*. +
This knowledge base (just a JSON array of ddot events) can be converted to many other graph formats at https://graphinout.com[graphinout.com].

== Quick Ref

* Universal *typed link* and *property* syntax is `aaa .. bbb.. ccc`.
* Link type can be left out: Use `aaa .... ccc` for a simple link.
* Append more to same subject with `..bbb.. ccc` lines.
* *Meta-data* can be appended behind `,,`.
* Spaces and tabs don't matter. Incomplete triples are ignored. An omitted subject continues the
 previous one — across blank lines, to the end of the file.
* Annotate a document: `ddot.it/this` refers to the doc in which ddot.it is used.

See the link:user-guide.html[User Guide] for the full syntax reference and more link:user-guide.html#commands[commands] (`ddot.it/COMMAND`).
