= ⚇ ddot.it Plain Text Reader
:page-title: Plain Text Reader
:page-parent: Developer Guide
:page-nav_order: 6

A ddot.it link:../developer-guide.html#reader[reader] for plain text files (`.txt` and similar).
It recognizes triples in <<plain-text,plain text>>.

NOTE: Some examples use the link:../user-guide.html#this-command[ddot.it/this] command.

== Standard Syntax

[[plain-text]]
=== Plain Text

Any line in a plain text file can contain ddot.it triples.

----
My notes file.
ddot.it/this ..project.. Code Red
..author.. Alice
Project Alpha .. depends on .. Project Beta
Project Alpha .. status .. active
----
